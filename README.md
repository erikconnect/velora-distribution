# @velora/css

Declarative CSS motion with zero animation runtime JavaScript. Optional Velora Skins layer.

Prepared for distribution; not yet published to npm.

After publication:

```sh
npm install @velora/css
```

```css
@import "@velora/css/motion-core";
```

Documentation: https://docs.veloracss.io/
Showcase: https://veloracss.io/

Use motion-core for host-agnostic motion, theme for Skins, or the default entrypoint for the full bundle. Modern CSS features use progressive enhancement; test target browsers and respect reduced-motion preferences.

Canonical development remains separate. This repository distributes reviewed CSS snapshots, not the private development history.
